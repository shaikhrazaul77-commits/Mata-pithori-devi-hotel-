MATA PITHORI DEVI HOTEL — WAITER APP

FILES:
- index.html: app
- manifest.json: installable app metadata
- sw.js: offline app shell caching
- icon-192.png / icon-512.png: app icons

FREE HOSTING:
1. Create a GitHub account and a PUBLIC repository (e.g. mata-pithori-waiter).
2. Upload all five files to the repository root. Keep index.html named exactly index.html.
3. Open Settings > Pages. Under Build and deployment choose Deploy from a branch, branch main, folder /(root), then Save.
4. Wait for GitHub Pages to publish. Open the given https://...github.io/... link in Chrome on Android.
5. In Chrome menu (⋮), choose Install app or Add to Home screen.
6. Open it once online. The app shell is cached for offline opening after first successful load.

IMPORTANT STORAGE NOTE:
Orders and menu are saved in the browser's localStorage on this phone. They are NOT synced to another phone and may be lost if Chrome site data is cleared or the app/browser storage is removed. Use Saved Orders > Export backup regularly. App installation does not guarantee permanent data storage.

The menu was transcribed from the supplied image. A few local dish names may need checking; use Edit Menu & Prices to correct names/prices. Prices such as boiled egg / cold drink sizes were separated into options based on the image.
